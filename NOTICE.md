## Chummer5a (GPL-3.0)

Os arquivos em `content/fichas/sr5/` são **derivados dos dados do Chummer5a**:

- Projeto: https://github.com/chummer5a/chummer5a
- Licença: GNU General Public License v3.0 (GPL-3.0)
- Arquivos de origem: `Chummer/data/*.xml` e `Chummer/lang/pt-br_data.xml`
- Versão usada: o commit fica registrado em `content/fichas/sr5/meta.json` (`chummerCommit`)

Esses dados foram convertidos de XML para JSON pelo script `scripts/fichas-sr5`.
O Chummer5a não inclui textos descritivos dos livros (apenas nomes, números e
referências de página), e este projeto também não. Todas as explicações exibidas
na interface foram escritas pelos autores deste projeto.

As regras derivadas implementadas no motor de regras (limites, monitores de
condição, validações de criação) foram conferidas com o código-fonte C# do
Chummer5a, também licenciado sob GPL-3.0.

Como os dados derivados estão sob GPL-3.0, quem redistribuir este projeto
precisa respeitar os termos dessa licença.
